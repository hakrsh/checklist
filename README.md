# Checklist

A single-file checklist app — just open `index.html`, no build or install needed.

## Features

- Add items, or paste a multi-line list and each line becomes an item
- Check items off with a progress bar and live status
- Double-click any item's text to edit it in place
- Select text, or drag the handle to reorder
- Delete with undo, plus clear-completed / clear-all with undo
- Saved in localStorage and synced across open tabs
- Cmd/Ctrl+Z to undo the last action

## Usage

Open `index.html` in any modern browser. All data is stored locally in your browser.
